앱 이름: Cavalier Shorts Uploader
시행일: 2026-11-26

이 앱이 하는 일

Cavalier Shorts Uploader는 유튜브 채널 카발리에의 AI 실험실 운영자가 본인 채널에 영상을 올리기 위해 쓰는 개인용 스크립트입니다. 다른 사용자를 위한 공개 서비스가 아닙니다. 업로드에는 YouTube Data API의 youtube.upload 범위만 사용합니다.

수집하는 정보

다른 사용자의 개인정보는 수집하지 않습니다. 운영자가 구글 계정으로 로그인하면, 업로드에 필요한 OAuth 토큰만 운영자 본인 PC에 로컬로 저장됩니다. 이 토큰은 서버나 외부 저장소로 보내지지 않습니다.

이용 및 공유

수집·저장된 정보를 제3자와 공유하거나 판매하지 않습니다. 토큰은 운영자가 본인 채널에 영상을 업로드하는 목적에만 사용됩니다.

YouTube API 서비스

이 앱은 YouTube API 서비스를 사용합니다. 사용 시 YouTube 서비스 약관과 Google 개인정보처리방침이 적용됩니다.

접근 권한 취소

구글 계정에서 이 앱의 접근 권한은 언제든 https://myaccount.google.com/permissions에서 취소할 수 있습니다.

Privacy Policy

App: Cavalier Shorts Uploader
Effective date: 2026-11-26

What this app does

Cavalier Shorts Uploader is a personal script used only by the owner of the YouTube channel 카발리에의 AI 실험실 to upload videos to that channel. It is not a public service for other users. It uses the YouTube Data API with the youtube.upload scope only.

Information collected

This app does not collect data from other users. When the owner signs in with a Google account, OAuth tokens needed for uploading are stored only locally on the owner's PC. Tokens are not sent to a server or any external storage.

Use and sharing

No data is shared with or sold to third parties. Tokens are used only to upload videos to the owner's own YouTube channel.

YouTube API Services

This app uses YouTube API Services. Use is subject to the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions.
