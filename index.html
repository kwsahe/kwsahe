rag-report

문제 정의
건설현장 사고 상황을 입력했을 때 관련 중대재해처벌법, 산업안전보건법 조항과 위반 가능성을 빠르게 확인할 수 있도록 돕는 시스템이 필요했습니다.
데이터 흐름
법령 PDF를 전처리한 뒤 검색 가능한 문서 단위로 나누고, 사고 시나리오와 유사한 조항을 검색해 보고서 화면에 근거로 연결했습니다.
사용 기술
Python, pdfplumber, ChromaDB, BM25, Ollama를 활용해 PDF 추출, 하이브리드 검색, 응답 생성 흐름을 구성했으며, Google Colab Pro를 연결해 Qwen2.5-14B와 EXAONE 모델 추론을 처리했습니다.
내 역할
팀 개발로 데이터 전처리, 검색 인덱스 구성, RAG 응답 흐름, 안전관리 대시보드와 사고 보고서 화면을 모두 구현했습니다.
결과 화면
안전관리 대시보드와 사고 보고서 자동 작성 화면을 통해 사고 정보, 판단 근거, 관련 조항을 한 화면에서 확인할 수 있게 구성했습니다.
한계와 개선점
법령 조항의 최신성 관리와 답변 검증 체계를 더 강화하고, 사고 유형별 평가 기준을 구조화하면 실무 적용성이 높아질 수 있습니다.
Python · Streamlit · SQLite
